# Place Photo

เว็บแอปสำหรับจัดรูปภาพบนกระดาษ A4 ใช้งานบนมือถือได้ เปิด `index.html` ในเบราว์เซอร์เพื่อใช้งาน

- เพิ่มรูปจากมือถือหรือคอมพิวเตอร์
- ลากเพื่อย้ายและใช้สองนิ้วปรับขนาด
- ย้อนกลับ ลบรูป และบันทึกเป็น PNG ขนาด 2480 × 3508 พิกเซล

ไฟล์ HEIC/HEIF จะถูกแปลงเป็น JPEG ภายในเบราว์เซอร์เมื่อจำเป็น เพื่อให้ใช้งานกับ Chrome บน Android ได้ โดยไม่ได้ส่งรูปไปที่เซิร์ฟเวอร์ ตัวแปลงใช้ [heic-to 1.6.7](https://github.com/hoppergee/heic-to) ภายใต้สัญญาอนุญาต LGPL-3.0 (ดู `vendor/HEIC-TO-LICENSE.txt`)
